Machine Learning Algorithm Types

Digital Portfolio · A Visual Framework

Introduction

Machine learning is a collection of very different ideas about how computers can learn from data. Some algorithms learn from labeled examples, while others look for hidden structure in unlabeled data. Some excel at spreadsheets and others at images, text, or creating new content. Choosing the right tool starts with understanding these differences.

Description

This project is an infographic that organizes ten widely used algorithms into a single framework. Each algorithm is classified as Supervised or Unsupervised, mapped to the domains where it is used (Tabular Data, Computer Vision, NLP, Generative AI), and paired with example applications and a short explanation of how it works.

Objective

  • Present at least 8–10 machine learning algorithms in one clear visual framework.
  • Classify each by learning type, application domain, use cases, and mechanism.
  • Show how the algorithms relate to and differ from each other so a reader can quickly pick a sensible starting point.

Process

  1. Research: reviewed textbooks and original papers to select ten algorithms that span the main learning types and domains.
  2. Classify: labeled each algorithm as supervised or unsupervised and mapped it to Tabular Data, Computer Vision, NLP, and Generative AI.
  3. Summarize: wrote a short mechanism and concrete real-world use cases for each.
  4. Design: built a visual hierarchy (type → domain matrix → detail cards) with consistent color coding.
  5. Review: checked accuracy against references and tested readability on mobile and desktop.

Tools and Technologies Used

  • HTML / CSS / JavaScript: page layout, styling, and the interactive filters
  • Claude: AI-assisted drafting and structuring
  • Python, scikit-learn, PyTorch: reference implementations of the algorithms described

Value Proposition

Unique Value

  • Three layers in one view: type, domain, and detail.
  • Color-coded and filterable, so differences are visible at a glance.
  • Plain-language explanations that stay technically accurate.

Relevance

  • Algorithm selection is a core skill for data science and AI roles.
  • Covers both classic methods and modern deep learning and generative AI.
  • Useful as a quick study guide or a communication tool for non-technical audiences.
